# Catalogue workspace
Mode: Operate. Native desktop; direct Qt/QML implementation authorised by owner.

## Direction contract
THESIS: A screening-room catalogue gives video imagery the room; replace the crowded toolbar and boxed-card arrangement.
OWN-WORLD: Warm charcoal, ivory text, muted amber selection; flat shelves, fine seams, compact native controls.
STORY: Choose a folder or rating view, find a video visually, scrub it, inspect and annotate it.
FIRST VIEWPORT: Resizable and collapsible filter sidebar (264px initially) with current view selector, count, and three-line sort menu, fuzzy search, tag inclusion/exclusion, and duration/size/rating ranges; no catalogue header; edge-to-edge thumbnail shelves with detached filenames. A tabbed bottom inspector opens on selection without reducing the grid width; its tabs disappear without selection. Signature: pointer position reveals a time cursor, returning to the poster on leave; native momentum scrolling with hover previews paused during motion; a short color transition for controls.
FORM: Screening-room shelves, candidate 4; seed c1951a7c. Other candidates: contact sheet, editing bin, accession ledger, file cabinet, museum records, broadcast monitors. Console discipline contributes stable panels; drum-machine discipline contributes precise timeline position. Decorative challenger worlds declined for task clarity.
